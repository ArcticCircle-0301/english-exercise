# 大学英语第二册 · 词汇与短语练习

面向大学英语第二册的在线练习网页，包含分单元词汇选择题、短语填空、答题计时、成绩排行和简单的管理员后台。

## 在线使用

GitHub Pages：<https://arcticcircle-0301.github.io/english-exercise/>

学生可以注册账号或使用已有账号登录。点击登录页下方的“管理员入口”可打开管理员登录页。

## 功能

- **词汇精练**：6 个单元，单项选择，答题后显示翻译和解析。
- **短语练习**：6 个单元，从选项中选择合适的短语完成句子。
- **限时答题**：每题 30 秒；超时按答错计分。
- **成绩与排行**：按模块和单元查看成绩，分数相同时用时较短者排名靠前。
- **管理员后台**：查看注册用户、练习记录和成绩；封禁/解封用户、调整成绩。
- **登录信息**：注册及登录时会尝试查询并记录 IP 地址和大致地区。

## 本地运行

这是一个无需构建步骤的静态页面。克隆仓库后，在浏览器中打开 `index.html` 即可；也可以用任意静态 HTTP 服务器托管仓库根目录。

## 数据服务配置

应用使用 JSONBin 保存用户、练习记录、封禁名单和成绩。当前数据桶 ID、JSONBin 主密钥及管理员密码在 `index.html` 的客户端 JavaScript 中配置。

> **安全提示：** 静态网站中的前端配置对所有访问者可见，不适合存放私密凭据。不要将此实现用于需要安全认证或保护个人信息的生产场景。公开部署前应轮换已暴露的密钥和密码，并将鉴权及数据读写迁移到受保护的服务端。IP 地址和地区信息也属于敏感数据；使用前应告知用户并遵守适用的隐私要求。

如果管理员登录后后台显示数据加载错误，请检查 JSONBin 主密钥、数据桶 ID 和对应桶是否仍可访问。恢复数据桶时，应使用空数组初始化新桶，并在 `index.html` 中更新相应 ID；原桶不可访问时，其历史数据不会自动恢复。

## 部署

仓库通过 GitHub Actions 将 `main` 分支部署到 GitHub Pages。推送到 `main` 或在 Actions 页面手动运行 **Deploy static content** 工作流即可触发部署。

## 项目文件

- `index.html`：应用界面、样式、登录和练习逻辑、数据服务配置。
- `data.js`：词汇题、短语题及短语选项数据。
- `.github/workflows/static.yml`：GitHub Pages 部署工作流。
